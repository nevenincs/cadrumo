`atomic_write.py` separates four write policies. Standard and hardened writes stage beside the destination, fsync the staged file, replace atomically, then best-effort sync the directory; hardened staging uses exclusive, unpredictable names, restrictive mode, close-on-exec flags where available, and a complete short-write loop. Deferred publication keeps the hardened staging guarantees for incremental producers and deletes unpublished staging files on every exit. The best-effort tier skips fsync only for rebuildable caches. `DurableWriteBatch` can defer directory durability for content-addressed or re-derivable data, and explicitly excludes keys, pointers, and session records. These choices separate atomic visibility from crash durability and make the lower-durability batch opt-in.

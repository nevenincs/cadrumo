# Tauri desktop shell

The desktop shell is the `cadrumo` host binary (crate `cadrumo-desktop`) in `native/desktop/src-tauri`, with a React frontend in `native/desktop/frontend`. With no arguments on an interactive desktop it opens one window; with arguments, after `--headless`, or without a desktop it forwards to the installed Python CLI. `--gui` forces the window and fails with the desktop-unavailable exit code when there is no desktop. The shell presents, launches and relays: it holds no runtime connection, session, credential or authority. Sign-in is a short-lived child of the packaged CLI, and the per-user manager alone starts the runtime. Windows (WebView2) has every feature. On Linux the window, docs, logs, terminal and instance lock exist, but sign-in, context menus and manager dispatch return `unsupported`. macOS is refused when the window starts. [entry](../../../../native/desktop/src-tauri/src/main.rs#L30), [modes](../../../../native/desktop/src-tauri/src/launch.rs#L27), [macOS](../../../../native/desktop/src-tauri/src/app.rs#L105), [contract](../../../../native/CONTRACT.md#L715).

The desktop is a standalone CMake project: `cmake -S native/desktop --preset desktop-windows-x64` configures into `build/<preset>`, and the source build adds it only when a desktop image is staged. It needs `CADRUMO_NATIVE_CONTRACT` and `CADRUMO_DESKTOP_PACKAGE_ROOT`. Targets are `desktop-frontend-*` (install, build, check, test), `desktop-host-*` (prepare, build, test, clippy), `desktop-run` and test targets. Under `scripts/`, `frontend-install.mjs` runs `npm ci` only when the tree differs from the lockfile, `content-build.mjs` fingerprints inputs, `backend-snapshot.mjs` copies the crate and path crates into the build tree, and `tauri.mjs` writes `tauri.conf.json` there and runs the pinned Tauri CLI (`build --no-bundle -- --locked`), refusing a Cargo binary that differs from the image CMake declares. `tauri.conf.json.in` is read as plain JSON; `configuration.mjs` adds identity, a relative `frontendDist`, icons and a `frame-src` set to the docs origin. The crate uses Tauri 2, `portable-pty` and a clipboard plugin through its Rust API only; `build.rs` embeds the contract. `just dev` serves the frontend in a browser and compiles no Rust. [CMake](../../../../native/desktop/CMakeLists.txt#L68), [presets](../../../../native/desktop/CMakePresets.json#L10), [tauri.mjs](../../../../native/desktop/scripts/tauri.mjs#L144), [configuration](../../../../native/desktop/scripts/configuration.mjs#L136), [crate](../../../../native/desktop/src-tauri/Cargo.toml#L1), [dev](../../../../justfile#L93).

The host uses request/response commands plus Tauri `Channel` streams and emits no events. Each module declares commands with `commands!`; `app.rs` composes them behind a per-launch token, handed once by an init script to the top frame on a shell origin and presented as a `token` argument or `x-cadrumo-token` header. The shell module serves the environment, `https:`/`mailto:` links, a bounded clipboard, a Windows-only context menu, window controls and the single-instance lock. Sign-in commands run the packaged `aeat` CLI after a digest check, with the password on stdin. The `docs` module serves a read-only `cadrumo-docs` scheme from a manifest allow-list with containment checks, a per-response CSP and the shell origins as frame ancestors. The `logs` module tails the Python log, manager JSONL and host diagnostics on a 100 ms tick into a ring feeding a bounded set of channels. The `terminal` module opens one PTY per kind (console, Python, TUI) with tagged binary frames and credit backpressure. The `manager` module requests manager launch through the existing Explorer desktop via a Python shim and owns or stops no manager or runtime process. [dispatch](../../../../native/desktop/src-tauri/src/app.rs#L72), [shell](../../../../native/desktop/src-tauri/src/shell/mod.rs#L200), [docs](../../../../native/desktop/src-tauri/src/docs/mod.rs#L71), [logs](../../../../native/desktop/src-tauri/src/logs/mod.rs#L38), [terminal](../../../../native/desktop/src-tauri/src/terminal/ipc.rs#L97), [manager](../../../../native/desktop/src-tauri/src/manager.rs#L180), [shim](../../../../native/desktop/src-tauri/src/python/manager_dispatch.py#L1).

Build-script tests are `node --test` files run by `desktop-paths-test`, `desktop-configuration-test` and `desktop-build-test`. Rust tests run through `desktop-host-test` (feature `live-package-tests`, needs a built package) or `tests/run-backend.ps1`. `desktop-headless-test` compares CLI passthrough with the interpreter. The packaged harness (`desktop-packaged-test`, `tests/run-packaged.ps1`) needs an assembled package with documentation and an interactive, non-Session-0 desktop; it builds a separate host with `webview2-remote-debugging`, drives WebView2 over DevTools, and sends real keys and clicks while the window is foreground. Browser-level frontend tests run against a simulated host, so they show nothing about the token, scheme, WebView2, PTYs or window lifecycle. [runner](../../../../native/desktop/tests/run-packaged.ps1#L75), [host](../../../../native/desktop/tests/packaged/host.mjs#L24), [procedure](../../../../native/CONTRACT.md#L1171).

Observations to check against current code. The macOS preset exists while the window refuses macOS. `tauri.conf.json.in` is never configured by CMake despite its suffix. The terminal sources hold no Job Object or process-group code and kill the direct child, while the manual checklist expects window close to end every terminal child. When package verification reports the manager target unavailable, dispatch installs one at user scope before dispatching, which deserves a check against the runtime lifecycle policy. The contract's command tables omit `manager_*`. A killed install can leave `.cadrumo-npm.lock`. [terminal](../../../../native/desktop/src-tauri/src/terminal/session.rs#L434), [install](../../../../native/desktop/src-tauri/src/manager.rs#L194), [lock](../../../../native/desktop/scripts/frontend-install.mjs#L42).

## Working notes

- New command: add it to its module's `commands!` list (names must be distinct across modules, checked at startup), then mirror it in the frontend `HostCommands` map and `tauriHost.ts`. [composition](../../../../native/desktop/src-tauri/src/app.rs#L22), [contract](../../../../native/desktop/frontend/src/ipc/contract.ts#L645).
- The token is read once and never posted to the docs frame, a URL, storage or a log. [contract](../../../../native/desktop/frontend/src/ipc/contract.ts#L21).
- Ports come from `development-server.json`; an occupied port is an error. [README](../../../../native/desktop/frontend/README.md#L11).
- The host refuses to start unless the shell policy frames exactly the docs origin. [contract](../../../../native/CONTRACT.md#L784).
- `CADRUMO_DESKTOP_DOCS_ROOT` applies only in development builds. [docs](../../../../native/desktop/src-tauri/src/docs/mod.rs#L24).
- Packaged builds refuse `WEBVIEW2_*` overrides; `webview2-remote-debugging` is never for distributed builds. [overrides](../../../../native/desktop/src-tauri/src/shell/webview_environment.rs#L8).
- Session 0 has no window station; check the window from an interactive logon. [contract](../../../../native/CONTRACT.md#L1225).

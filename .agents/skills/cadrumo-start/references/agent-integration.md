# Agent integration

Five Python owners are distinct: `cadrumo` is the deterministic tax/profile product, `cadrumo_runtime` owns generic login/custody/session/operation authority, `cadrumo_client` owns shared client contracts and transport, `cadrumo_agent_service` manages provider policy and agent processes/stores, and `cadrumo_harness` owns MCP and authored agent material. The actual agent implementation is the separately built `cadrumo_agent` project. Native desktop supervises the service; the service supervises cadrumo-agent. Provider/lane/model capabilities come from the agent, never tax/runtime or frontend lists. Tax-domain model extraction keeps its existing consent and evidence policy. [Service entrypoint](../../../../src/cadrumo_agent_service/main.py), [service composition](../../../../src/cadrumo_agent_service/service.py), [MCP entrypoint](../../../../src/cadrumo_harness/mcp/main.py).

## Package ownership

CMake requires the cache-only `CADRUMO_PACKAGE_AGENT_SOURCE_DIR`, a local project with `pyproject.toml`; it never reads that choice from the environment. `agent_project` builds a private wheel and records version/name/SHA-256; target locks in `native/agent/` require exact shared dependency versions. The package installs the agent beside the fixed Cadrumo wheel cohort. `agent-checksum`, `agent-uninstall`, `agent-rebuild` and explicit `agent-lock-<target>` targets own maintenance. Nothing installs/downloads the agent at runtime or imports a checkout for packaged acceptance. [CMake owner](../../../../native/cmake/Agent.cmake), [wheel/lock admission](../../../../dev/packaging/native/agent.py).

The package declares distinct `bin/cadrumo-agent-service` and `bin/cadrumo-agent` images. Service's fixed native entrypoint is `cadrumo_agent_service.main:main`; its service profile receives agent/relay/AEAT/Python image paths. The runtime/profile workers receive no agent paths. Agent image admits only its declared gateway, worker, version/store and `providers --declared --json` invocations; its worker re-executes that image. [Layout](../../../../native/package-layout.json), [environment profiles](../../../../native/application-environment.toml), [Windows hosts](../../../../native/cmake/platforms/Windows.cmake), [POSIX hosts](../../../../native/cmake/platforms/Posix.cmake).

`data/service-descriptors.json` is immutable package policy, included in manifest hashing. The service descriptor names exact image/module/digest, legacy opaque provider record capability and explicit non-person operation ceiling; a separate desktop-holder descriptor names allowed native desktop parents and has no provider record capability. Incremental native-image replacement refreshes image/parent and descriptor digests only after checking the existing manifest identity. A client cannot grant itself arbitrary namespace or operation/disclosure authority by changing request JSON. [Descriptor producer](../../../../dev/packaging/native/service_descriptors.py), [assembly](../../../../dev/packaging/native/assemble.py), [service client](../../../../src/cadrumo_client/transport/service_client.py).

## Native/service protocol

Native runs the verified packaged service with `serve --profile-id UUID`, writes one bounded newline-terminated `{"bearer":"TOKEN"}` JSON frame and keeps stdin open. EOF/unexpected additional input stops the service. Service registers its exact verified runtime connection, starts administration, then emits `service_ready` with protocol 1, admin port and runtime boot/connection/profile/service identities. The native person's generic held runtime connection authorizes this exact recipient; service polls the same connection for its lease. Service/agent connections remain non-person. [Entrypoint](../../../../src/cadrumo_agent_service/main.py), [startup frame](../../../../src/cadrumo_agent_service/contracts.py), [native decoder](../../../../native/desktop/src-tauri/src/agent/launcher.rs), [native holder](../../../../native/desktop/src-tauri/src/agent/person.rs).

Administration binds an ephemeral loopback port separate from the model gateway. Each bounded exchange sends a length-prefixed raw bearer followed by versioned correlated JSON for catalog/status/set/remove/reset/auth/start/stop. Set declares secret length, waits for correlated `secret_ready`, then sends a distinct raw bounded key frame; the result is masked. Base URL omission preserves, empty clears. Provider changes retire the old agent tree; explicit start resolves committed state again. Admin remains usable when credentials are absent or agent startup refuses. Catalog is public before lease approval; private status/mutations/start require live admitted custody. [Admin server](../../../../src/cadrumo_agent_service/admin.py), [native admin transport](../../../../native/desktop/src-tauri/src/agent/admin.rs), [provider commands](../../../../native/desktop/src-tauri/src/shell/provider_settings/mod.rs).

Outer service events are `service_ready`, service-owned `agent_ready` (which includes workspace metadata), `refused` and `stopped`; failures preserve administration until authority/parent lifetime ends. This is separate from inner cadrumo-agent hosting v1. The inner frame is mandatory `version:1, credentials:{...}` even when empty, with optional `gateway_bearer`; the agent's ready answer requires `gateway_port`, `agent_version`, `hosting_contract`, with no `lane` or `workspace_root`. Neither protocol exports the profile DEK or invents an agent-store key. [Inner frame](../../../../src/cadrumo_agent_service/host/credential_frame.py), [controller](../../../../src/cadrumo_agent_service/host/controller.py), [outer composition](../../../../src/cadrumo_agent_service/service.py).

## Provider custody and catalog

Service `providers/domain`, `providers/application` and `providers/persistence` interpret settings. Generic runtime opaque CRUD/CAS preserves existing `cadrumo.provider_settings` namespace/key/schema/AAD and serialized v1 records. Absent/unreadable/refused remain distinct; persisted disabled blocks development fallback, reset returns unset, uncertain dispatch remains UNKNOWN. Profile DEK stays runtime-owned. Installed lanes have no environment fallback; declared development fallback is service policy after exact-profile admission. Keys travel on protected one-shot channels and agent stdin/worker pipe, never argv/environment/logs/MCP/conversation routes. [Opaque store adapter](../../../../src/cadrumo_agent_service/providers/persistence/store.py), [resolver](../../../../src/cadrumo_agent_service/providers/application/resolution.py), [record shape](../../../../src/cadrumo_agent_service/providers/domain/record.py).

Credential catalog comes from agent's bounded offline `providers --declared --json` schema 2, projected into the service credential contract. Full v1 provider/model/control metadata is separately derived from verified non-editable same-cohort agent modules, validated by the actual agent DTO, with unobserved health UNKNOWN and selectable false. Once ready, the service proxies the actual authenticated gateway catalog and rechecks exact generations after reading. Offline declarations do not assert readiness or invent provider-specific facts. [Credential catalog source](../../../../src/cadrumo_agent_service/adapters/agent_provider_catalog.py), [parser](../../../../src/cadrumo_agent_service/providers/domain/catalog.py), [full metadata projection](../../../../src/cadrumo_agent_service/adapters/provider_catalog_metadata.py), [live catalog](../../../../src/cadrumo_agent_service/service.py).

## Process, store and presentation owners

Service holds one exclusive profile-agent reservation through confirmed cleanup. Before serve it runs bounded version/stores-state/setup/migrate, preserves opaque revision expectations, copy-aside atomic publication and one rollback snapshot, refuses newer/unknown states and retains uncertain mutation/containment ownership. It watches exact runtime profile/session/configuration generations and fixed deadlines without extending person activity; revocation/profile switch/runtime loss closes admission and reaps the whole tree. Independent service locales in `locales/{en,es,ca,hu}.yml` merge into generated desktop chrome with tax/generic resources; tax loaders import no service catalog.

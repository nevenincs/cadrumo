# aeat-data (placeholder release)

This 0.0.0 release exists only so the PyPI project exists ahead of its
per-file size-limit request (the real corpus-sources companion wheel is
~139 MB, above the 100 MB default cap). The real `aeat-data 0.1.0` — the
official AEAT corpus source binaries consumed via the
`aeat-cli[corpus-sources]` extra — publishes once the grant lands. See
`https://github.com/nevenincs/aeat` (RELEASING.md) for the sequencing.

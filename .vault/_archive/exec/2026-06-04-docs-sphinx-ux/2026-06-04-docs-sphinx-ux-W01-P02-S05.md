# `docs-sphinx-ux` `W01.P02.S05`

Scope: `W01.P02.S05`.

## Description

Create the Furo variable stylesheet.
Define light and dark palette tokens, font stacks, link colors, sidebar logo sizing, content rhythm, admonition borders, card radius, and copy-button radius.
Keep the palette restrained and trust-first rather than one-note or official-agency-like.

## Outcome

The review build loads `aeat-docs.css`, and the browser inspection reports the expected teal brand color.
The first viewport has readable content width, visible warning emphasis, and stable sidebar branding.

## Notes

The stylesheet does not attempt broader route-card or reference-wrapper styling yet; those are downstream human-gated waves.

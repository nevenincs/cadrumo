# `public-product-name-clearance` research: `Public product name clearance`

Screen the retained public-name candidates before further creative work.

## Findings

- Use `Cadrumo` as the working public name.
- Keep `Cadrumo` legally provisional until formal clearance completes.
- Compare `Cadrumo` with `Cadro` and `Quadrum` in the mark search.
- Reject `Foliora` because an active textile brand uses the exact name.
- Reject `Sumera` because active AI software uses the exact name in finance content.
- Reject `Contura` because active accounting software and an active consumer app use the exact name.
- Reject `Formura` because active companies, a programming language, and the `formura.com` sale use the exact name.
- Flag `TAEA` as a high association risk because reversing `AEAT` may imply an official connection.
- Reject `AELO` because active exact-name software and consumer products crowd the term.
- Treat this as a web collision screen and not formal trademark clearance.
- Search Spanish, international, and EU marks before adopting any candidate.
- Search exact, phonetic, visual, and conceptual near-matches in relevant classes.
- Start with classes 9 and 42.
- Add class 35 or 36 only after counsel defines the actual commercial offer.
- Keep `AEAT` outside the product mark and use it only for true compatibility references.
- Treat the word mark, logo, and code as separate rights.
- Secure written ownership of every commissioned logo and visual asset.

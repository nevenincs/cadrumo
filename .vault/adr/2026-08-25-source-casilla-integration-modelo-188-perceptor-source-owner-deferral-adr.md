# `source-casilla-integration` adr: `modelo 188 perceptor source owner deferral` | (**status:** `accepted`)

## Problem Statement

The accepted source-connectivity framework requires a model-scoped source-owner
decision before a row carrier, source kind, binding, resolver, producer, or
census claim is introduced.  `2026-08-25-source-casilla-integration-modelo-188-perceptor-source-lifecycle-grounding-research`
grounds a genuine M188 type-2 perceptor fact family but no authoritative,
non-lossy Cadrumo owner.  This ADR decides the bounded refusal without
rewriting the direct manual summary surface or any historical design boundary.

## Considerations

- `2026-08-22-source-casilla-integration-adr` requires compatible fact and
  destination semantics, durable provenance, secure ownership, and encrypted
  replay/review before a connection can be asserted.
- `2026-08-25-source-casilla-integration-modelo-188-perceptor-source-lifecycle-grounding-research`
  separates the selected 2023-plus perceptor facts from the five manual summary
  targets, historic-era evidence, file presentation, and post-filing reads.
- `2026-08-24-registry-completeness-closure-modelo-188-design-era-coverage-reference`
  retains separate temporal and export predecessor obligations; neither is a
  source owner.

## Considered options

### Connect the manual summary, record design, file route, or read surface now

Rejected.  None owns the native type-2 fact set or its per-perceptor identity,
repetition, correction, and absence semantics.

### Treat the unmodelled type-2 family as not applicable

Rejected.  The official selected-era record requires genuine perceptor facts;
the absent owner is a grounding gap, not an inapplicability decision.

### Hold the exact type-2 family at a model-scoped grounding boundary

Accepted.  Preserve existing manual summary input and independent temporal/export
work while refusing to promote them into an insurer/perceptor source lifecycle.

## Constraints

- The decision applies only to Modelo 188 revision `2023-y-siguientes` and
  period `0A`; it neither restores 2019--2022 selection nor claims an earlier
  design's facts or offsets.
- Existing manual summary casillas `01`--`05` remain direct registry targets.
  This decision does not treat them as a row source, declare an unmodelled
  manual row lifecycle, or weaken their separate manual contract.
- An AEAT layout, file presentation, producer vocabulary, generic transport, or
  filed-declaration read is not admissible proof of pre-filing acquisition or
  source ownership.
- No M188 registry, source taxonomy, census, binding, resolver, parser,
  producer, layout, export, or runtime implementation is authorized.

## Implementation

`source-connectivity-campaign` owns the Modelo 188 `2023-y-siguientes/0A`
type-2 perceptor fact family as `grounding_blocked`.  It is bounded to the
external declarant/insurer-held row lifecycle and must remain distinct from the
five manual summary casillas.  No census row is created: current evidence
establishes the official fact family but not the framework's candidate
fact/grain/destination/owner tuple.

No binding, resolver, fixture, source-owned perceptor export, or M188 writer
follows from this refusal.  Historic-era acquisition and a future rendering
contract remain separately governed; satisfying either alone does not reopen
this source boundary.

### Reopening predicate

A later, explicitly approved 2023-plus M188 source slice may reopen only if it
proves all of the following:

1. An authoritative encrypted Cadrumo carrier and acquisition route owned by
   the actual declarant/insurer side, with a durable row identity for each
   perceptor and required representative relationship where applicable.
2. The entire admitted row grain: perceptor identity and province, modality,
   signed income, additional information, reductions, withholding base/rate/
   amount, accrual exercise, key, repeated-row count, zero/absence, correction,
   collision, and override semantics.  Summary totals may be derived only after
   this native row contract is established.
3. A law-selected 2023-plus registry semantic map and row/binding destinations
   that preserve the selected fact meanings and exclude AEAT-reserved transport
   fields.
4. Resolver ownership, source fingerprint/provenance, encrypted persistence and
   reload, deterministic replay, diagnostics/refusal, and an operator review
   route for the same source-to-target identity.
5. Separately grounded historic coverage and export proof if an export is
   proposed.  A record coordinate or generic file transport may validate output
   only after the source proof; it cannot satisfy it.

## Rationale

The accepted boundary follows `2026-08-22-source-casilla-integration-adr`: it
keeps the required perceptor lifecycle visible and preserves manual summary
input without inferring a source from an aggregate, a presentation contract, or
a post-filing observation.  It supplies one falsifiable reopening path rather
than creating an unowned candidate or an accidental M188 filing claim.

## Consequences

- S232 closes as a model-scoped `grounding_blocked` refusal for the M188 type-2
  source family, not as a source connection, manual-by-design finding for rows,
  or filing capability.
- Future M188 work must acquire the named secure owner before adding a census
  candidate, source kind, row binding, resolver, fixture, or source-owned
  repeated-record export.
- The five direct manual summary casillas and the separate 2023-plus temporal
  and future export contracts remain available under their existing boundaries.

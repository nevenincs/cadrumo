# `language-sync` reference: `Canonical language state and live synchronization gaps`

## Summary

Static discovery on 2026-10-15 found one durable preference and several disconnected presentation snapshots. These findings ground the authorized language amendment; tests establish behavior separately.

- `src/cadrumo/domain/user_profile/setup_answers.py` defines `PROFILE_OUTPUT_LANGUAGE_PATH` as `preferences.output_language`. `src/cadrumo/application/user_profile/fact_write.py:129` commits ordinary profile changes with record revision/content-digest preconditions, then mirrors the bucket-local nonsecret language hint and refreshes the writing process snapshot.
- `src/cadrumo/application/user_profile/language_resolver.py:68` snapshots the canonical preference. Rendering reads that snapshot without storage IO. `src/cadrumo_runtime/commands/profile_language.py:12` preserves explicit invocation/settings overrides before the selected-profile hint and default.
- `src/cadrumo/entrypoints/tui/tests/test_manager_language_switch.py:268` covers the existing manager picker and encrypted preference write. Before this work, the root subscriptions at `src/cadrumo/entrypoints/tui/app.py:314` handled retirement and upgrade notices, with no language invalidation.
- Before this work, `native/desktop/frontend/src/App.tsx` selected a saved browser language only from bundled documentation languages. `src/components/Settings.tsx` used the shared NativeSelect but wrote only local preferences; `src/shell/useDesktopEnvironment.ts` performed a one-shot host read. No state library was installed.
- The documentation switcher is generated by `dev/docs/language_switcher.py`. Its ordinary cross-root links did not notify the shell of a selected language. `docs/_static/cadrumo-desktop-bridge.js` and the shell DocsFrame already enforce exact source/origin messages, providing the existing bridge boundary to extend.
- `native/desktop/src-tauri/src/agent/person.rs` owns the correlated verified session-holder exchange. Language controls can use that transport without depending on agent-service availability; canonical writes remain registered profile mutations. Background observations must not record person activity.

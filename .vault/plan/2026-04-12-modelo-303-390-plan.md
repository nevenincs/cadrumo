# modelo-303-390 plan (#62)

Date: 2026-04-12
Branch: `feature/62-modelo-303-390`
Issue: wgergely/aeat#62

## Summary

Ship two concrete `FilingBuilder` subclasses alongside the existing
`Modelo130Builder`, plus their hand-curated pydantic casilla
schemas, plus a `FilingValidator` rule that reconciles a Modelo 390
draft against the four Modelo 303 quarterly drafts it was built
from. Zero public API churn beyond two additional `__all__`
exports.

## Steps

1. **Schema modules.** Create
   `src/aeat/application/filing/_builders/_modelo_303_schema.py` with
   `MODELO_303_SCHEMA` (18 casillas per the ADR) re-using
   `StaticCasillaSchema` / `StaticCasillaCollection` from the
   existing `_modelo_130_schema.py`. Create
   `_modelo_390_schema.py` with `MODELO_390_SCHEMA` (15 casillas
   per the ADR). No re-export at the `aeat.application.filing` public level —
   these are accessed via `default_schema_provider()` only.

2. **Modelo303Builder.** Create
   `src/aeat/application/filing/_builders/modelo_303.py`. Mirror the
   `Modelo130Builder` structure: literal/default first pass, then
   a bounded fixed-point loop for formula casillas. Compute each
   `(base, tipo, cuota)` triple. Use `_as_decimal` helper pattern.
   Register in `_BUILDER_REGISTRY`.

3. **Modelo390Builder.** Create
   `src/aeat/application/filing/_builders/modelo_390.py`. Read
   `inputs["_quarterly_303"]` as `tuple[FilingDraft, ...]`;
   validate shape (exactly 4, all `modelo == "303"`, periods form
   `{year}Q1..Q4` matching the ejercicio). Build a lookup
   `dict[casilla_id, Decimal]` per quarter. Populate every sum
   casilla as `COMPUTED` with a synthetic trace over the
   quarterly draft_ids. Register in `_BUILDER_REGISTRY`.

4. **Validator extension.** In `src/aeat/application/filing/_validator.py`
   add `quarterly_303_drafts` kwarg to `FilingValidator.__init__`
   and a private `_validate_quarterly_reconciliation` rule that
   runs for `modelo == "390"`. Add a self-consistency check on
   each 303 draft. All findings use `Translatable`
   (`es`/`en`/`hu`).

5. **build_draft wiring.** In `src/aeat/application/filing/__init__.py`
   extract `inputs["_quarterly_303"]` (if present) and thread it
   into the `FilingValidator` constructor. Update the public
   `__all__` to include `Modelo303Builder` and `Modelo390Builder`.
   Update the `_builders/__init__.py` registry.

6. **testing helpers.** In `src/aeat/application/filing/testing.py` extend
   `default_schema_provider()` to register all three collections.
   Re-export `MODELO_303_SCHEMA` / `MODELO_390_SCHEMA`.

7. **Unit tests.** Extend `src/aeat/application/filing/test_filing.py` with
   `TestModelo303Builder`, `TestModelo390Builder`, and
   `TestModelo390CrossValidation` classes covering every case
   from the ADR. Hand-calculated arithmetic, zero mocks.

8. **Docs.** Update `src/aeat/application/filing/__init__.py` docstring
   example to mention the 303 / 390 pathways. No README changes
   (per instruction).

9. **Local gate.** Run `just lint`, `just typecheck`, `just test`,
   `just hooks`. Fix root causes only — no skips.

10. **Exec records + code review + PR.** Write exec step and
    summary under `.vault/exec/2026-04-12-modelo-303-390/`, run
    the `vaultspec-code-review` skill, commit, then open the PR
    against `main` with `Closes #62`.

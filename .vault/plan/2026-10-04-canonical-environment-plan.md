# `canonical-environment` plan

Make the Python core storage owner the single declaration of every location and environment control, project it into one schema 1 native contract, and give installed builds a per-user, per-channel, cwd-independent default root that both resolvers prove against generated vectors.

## Description

Approved 2026-10-04

Authorization basis: the user accepted `2026-10-04-canonical-environment-adr` on 2026-10-04 (relayed by the CADRUMO-RUNTIME-MANAGEMENT session as "all approved!"), and the user directed on 2026-10-04 that location and environment are the orchestrator session's (CADRUMO-BUILD-TAURI-TECHNICAL) to settle. That acceptance plus the directive authorize the six Steps below and their in-scope corrections. S02, S03 and S06 execute under the same accepted ADR but edit files other sessions own; an executor starts them only after the named owner agrees in writing.

## Parallelization

S01 runs alone first, owned by CADRUMO-BUILD-TAURI-TECHNICAL. Nothing else starts until S01 is committed: S02, S03, S05 and S06 read the declaration it creates, and S04 consumes the contract S02 emits.

After S01, two assignments run at once:

- S02 and S03 as one coordinated pair owned by CADRUMO-BUILD-RUNTIME, in that order, because S03 consumes the `contract.rs` S02 generates. Neither starts before that session agrees in writing. S03 also agrees the `native/platform/Cargo.toml` patch order with the desktop-shell S07 executor, who adds a feature-gated dependency to the same manifest.
- S05 owned by CADRUMO-BUILD-TAURI-TECHNICAL. Its executor prepares the gate while S02 is in progress and lands it after S02 so the gate is green on its first commit; no expected-failure marker is used.

S04 waits for S02 (the contract the desktop reads) and closes when desktop-shell S04, S07 and S11 have landed. S06 waits for S01 and closes on the manager workstream's report. Both are tracking Steps with no write scope in this plan.

Write ownership is disjoint per row: S01 owns the listed `src/cadrumo` files; S02 owns `dev/packaging/native/generate.py`, its test module and the `native_contract` OUTPUT list in `native/CMakeLists.txt`; S03 owns `native/platform/src/lib.rs`, `native/platform/tests/` and the `Cargo.toml` dependency list; S05 owns `dev/ci/tests/test_canonical_location_literal_gate.py` and its fixtures; S04 and S06 own nothing here. The worktree `Y:\code\cadrumo-worktrees\tui` is shared with the runtime, packaging and designer sessions and the Preflight auto-commit: re-read before patching, never stash, reset, clean or overwrite. Vault, ledger and commit mutations are serialized by the orchestrator. Rust builds from parallel executors use distinct `CADRUMO_CMAKE_BINARY_DIR` values.

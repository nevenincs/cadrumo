# `cross-domain-continuity` audit: `Wave 9 terminal audit`

## Scope

Wave 9 terminal verification after its period, localization, Sheets, and boundary work. It combines independent code review, a post-repair drift sweep, and fresh encrypted persona journeys.

## Findings

### wave-9-prorrata-facade-duplication | high | closed core axes had duplicate unused public facades

The domain and application prorrata-register facades republished two core-owned enums. S435 removed the duplicate exports while retaining private typing aliases, and an AST-plus-runtime boundary regression proved `aeat.core` is the sole public owner.

### wave-9-placeholder-parity | medium | dynamic translation arguments hid live contract drift

Three cross-period localization projections passed dynamic regular-expression argument splats, so the required static placeholder parity gate reported orphan tokens. S436 uses explicit arguments and a real encrypted persisted-report/render/reload workflow, retaining locale-neutral stored findings.

### wave-9-private-test-boundaries | medium | tests reached private modules despite public behavior seams

Seven private import statements were found. S438 migrated the owned M210/M303 cases to public behavior and facades; S439 moved the final prorrata diagnostic import to its existing public facade; S440 replaced private renderer helpers with root CLI JSON/text behavior. The final import-hygiene gate passed all 11 checks.

### wave-9-personas | low | taxpayer journeys calculate or refuse according to supported posture

Attribution entities, objective-estimation, salary, pension, and foreign-pension personas behaved as expected. M184 source completeness, incomplete local export layouts, and annual tariff-corpus gaps remain explicit registry or publication dependencies rather than product defects.

## Recommendations

- Keep canonical persisted verification strings locale-neutral and localize only at the CLI projection boundary.
- Maintain source-level import-boundary checks where runtime constant identity would not prove the importing path.
- Carry entity source-completeness and corpus-publication states forward as observable operator conditions.

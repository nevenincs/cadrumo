# `object-name-declustering` audit: `S31 teardown authority implementation review`

## Scope

Started with Step S31. Reviewed W04.P11.S31 against the accepted object-name
declustering ADR, the full W04 plan, and the receipt-scope and teardown-authority
audit. The complete replay implementation and test module were read, together
with the current ADR and detector diff. The review focused on the unit-of-work
teardown boundary, both verified-copy call sites, strict transaction evidence
cleanup, and whether the new generator-copy detector can fail for the original
regression rather than passing vacuously.

## Findings

No findings at any severity.

The accepted ADR now owns the invariant: cleanup outside the unit of work is
best-effort and cannot turn a verified result into failure, while cleanup whose
success is semantically meaningful remains strict. `_discard_verified_copy`
implements the former policy, including the Windows read-only retry and quiet
retention fallback. Both verified-copy `finally` blocks call that helper: the
post-apply gate copy and the isolated generator copy. The transaction-root
`shutil.rmtree` remains outside the helper and still raises a replay error when
its successful removal is part of the verified transaction disposition.

The existing post-apply detector injects `WinError 145` only for the
`cadrumo-object-name-post-apply-` root, asserts that the refusal was reached,
and proves the renamed bytes and successful result survive. The new generator
detector builds the generator-backed case, injects the same refusal only for
the `cadrumo-object-name-generator-` root, and has the matching anti-vacuity
assertion. It also asserts both generated bytes and renamed bytes, plus removal
of the transaction root, so an unexercised generator path or a rollback cannot
produce green evidence.

The generator call was temporarily changed to bare `shutil.rmtree`; the new
detector then failed through the cleanup exception and replay rollback. The
production call was restored byte-clean. The focused replay suite passes all
67 tests, with the reported lint, formatting, type, byte-compilation, and
whitespace checks green.

## Recommendations

No remediation recommendation is required. Preserve the separation between
best-effort verified-copy disposal and strict transaction-evidence cleanup,
and retain the generator detector's refusal and byte-preservation assertions
when replay teardown changes.

The installed probes are structurally strong. The source-isolation case changes an authored manifest in the snapshotted clean repository, proves candidate identity drift, repeats both installed semantic oracles, compares their filing-relevant evidence including installed payload identity, and restores the source bytes in `finally`.

The application persistence error declaration names the exact canonical class introduced concurrently, assigns a unique persistence-specific code and `FAIL` category, and reuses the established storage-bucket message.

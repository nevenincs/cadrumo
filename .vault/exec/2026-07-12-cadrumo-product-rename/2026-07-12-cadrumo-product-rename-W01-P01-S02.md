# Classify every public environment variable as product-owned or authority-owned

## Scope

- `product and authority environment-variable matrix`

## Description

- Read the accepted identity boundary and the approved execution plan.
- Locate the central settings authority semantically, then enumerate its live Pydantic fields directly.
- Confirm non-Settings MCP and developer controls with exact repository searches.
- Classify each public `AEAT_*` variable by the referent it configures.

## Outcome

The complete public surface contains 151 `AEAT_*` variables: 146 fields exposed
by `Settings` plus five direct MCP or developer controls. The decision rule is
referent-based: application, developer, storage, model-provider, telemetry, and
presentation controls are product-owned and move to the identical `CADRUMO_*`
suffix; variables that directly configure AEAT portals, authentication,
credentials, official authority data, or authority-session transport retain
`AEAT_*`. All 151 names resolve under that rule: 102 product-owned, 49
authority-owned, and zero ambiguous.

The retained browser, proxy, rate-limit, timeout, and live-surface controls are
not generic Cadrumo browser settings: their current consumers configure the
AEAT Sede session and its portal-specific interaction. The retained manuals,
normatives, IVA catalogue, and authoritative-language settings select official
AEAT data. If a future consumer makes any of these controls provider-neutral,
that new abstraction must introduce a Cadrumo-owned setting rather than silently
changing this authority contract.

### Ambiguous (0)

No public variable remains unresolved. Non-`AEAT_*` ambient controls such as
`NO_COLOR`, `FINANCIAL_BASE_CURRENCY`, `FINANCIAL_DEFAULT_CSV_ENCODING`, and
the generic site-health controls are outside the former product-prefix rename
and remain unchanged.

## Notes

Evidence came from the live `Settings.model_fields` surface, the MCP persona and
surface constants, and exact developer-tool searches. Tests, locale mirrors,
generated data, and arbitrary uppercase Python constants were not treated as
additional public variables. No production code or environment file was edited,
and no secret values were recorded.

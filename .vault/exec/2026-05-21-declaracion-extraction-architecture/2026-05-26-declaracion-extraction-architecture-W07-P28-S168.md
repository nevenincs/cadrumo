# declaracion-extraction-architecture W07.P28.S168

Surveyed the AEAT instructions corpus for M036, M180, M232, M349, M369, and M720 to determine whether the 6 PROVISIONAL `declaracion_pdf` extraction profiles can be grounded.

## Corpus survey findings

All 6 corpus instruction files are AEAT portal navigation HTML pages generated by the AEAT Sede content management system. Each file contains:
- Top-level navigation breadcrumbs and sidebar links
- Links to downloadable files (PDFs referenced as "Instrucciones (N KB - pdf)" or "Diseños de registro")
- Normative order citations (BOE references)
- ZERO embedded field-description text

The actual instruction content (sections like "Normas de cumplimentación", "En la casilla X consigne...") is loaded dynamically via JavaScript from Vignette CMS content IDs (VgnVCM-format identifiers, e.g. `b3552c121d27c610VgnVCM100000dc381e0aRCRD`). This content was NOT captured at download time; it requires JavaScript execution to render.

### M180 note

The `modelo-180-ayuda-presentacion.html` file has a richer structure — it contains a table-of-contents with section headers like "2.2. Ejercicio y modalidad de presentación" and "2.3. Declaración complementaria o sustitutiva". However, these are JavaScript `<option>` anchors pointing to VgnVCM IDs; the prose for each section is fetched asynchronously. No M180 field descriptions are in the file body.

### M232 and M349 note

The M232 procedure page references "Instrucciones (367 KB - pdf)". The M349 page references "Instrucciones (612 KB - pdf)". If these PDFs were added to the corpus they would very likely contain the printed-form field labels needed for verification. These are the highest-priority acquisition targets.

## Registry profile state — no changes made

All 6 profiles retain `provisional_pending_specimen = true`. No `corpus_round_trip_verified` tags were added. No `label_pattern` values were modified. The existing PROVISIONAL documentation comments in each profile remain accurate.

The grounding task requires acquiring the instruction PDFs linked from the AEAT pages, not the portal navigation HTML files. The corpus HTML files serve no grounding purpose for the `label_pattern` verification use case.

## Recommendation

Acquire the downloadable instruction PDFs for M232 (367 KB) and M349 (612 KB) as the highest-value targets — these informative modelos have structured summary blocks in their printed declarations (resumen de declaración) that are likely to match the existing label_pattern values. M720, M036, M180, and M369 each have printed-form PDFs accessible from the AEAT Sede but were not captured in the corpus download.

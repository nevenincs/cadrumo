# centralize the production modelo-work calculation route and its staged resolver ownership so runtime composition and authority share one declaration

## Scope

- `src/cadrumo/application/modelo`

## Description

- Declare the production calculation route as typed pre-mesh, mesh, conditional, post-mesh, and manual ownership.
- Derive source dispositions from resolver class contracts and validate complete, exclusive ownership.
- Make production resolver composition assert and consume the shared declaration at each stage.
- Project the reflective enrollment gate from the production declaration instead of a parallel resolver census.
- Exercise catalogue parity, mutation refusal, reflective enrollment, and live source-mesh behavior.

## Outcome

Production modelo calculation composition and future connectivity authority now share one public route declaration. Every binding source kind has exactly one canonical disposition; enrolled sources have exactly one resolver owner, deferred and reserved sources cannot acquire one, the conditional M303 annual-summary resolver is explicit, and manual input has a sole typed owner without an invented resolver.

## Notes

The former reflective enrollment test omitted the already-live conditional M303 resolver. It now derives enrolled resolver classes from the production route, removing the stale duplicate census while retaining public-export discovery as an independent gate.

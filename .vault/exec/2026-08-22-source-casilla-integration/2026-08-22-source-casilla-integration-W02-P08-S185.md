# ground which supported M100 filing formats carry repeated economic-activity casilla rows and their exact official coordinates

## Scope

- `.vault/research/2026-08-23-inventory-casilla-grounding-research.md`

## Description

- Locate governing decisions and implementation sites with `vaultspec-rag`, then confirm exact symbols and official corpus coordinates with targeted `rg` probes.
- Re-fetch the AEAT 2025 declaration dictionary and XSD and compare their activity-row cardinality, required siblings, and casilla paths with the bundled official corpus.
- Classify every supported outbound filing format and inspect the XML writer, parser, parity verifier, PDF surfaces, and existing fixed-width row renderer for semantic overlap.
- Submit the ruling to three independent Sol lanes covering official evidence, local semantic duplication, and adversarial architecture review.
- Amend the existing research record with the verified positive, negative, and blocking evidence.

## Outcome

Modelo 100 exercise 2025 XML is conclusively row-capable: `ActividadEstDirecta` repeats at most six times and carries 0177, 0181, and 0182 as `E1II7`, `E1G1`, and `E1G2`. No outbound PDF filing format or official repeated-PDF coordinate contract is present, so PDF renderer work is not authorized.

End-to-end XML emission remains dependent on a separate complete activity-envelope join. Every repeated XML row requires `TACT`; inventory owns only an opaque local activity identifier and must not fabricate TACT, IAE, estimation modality, or holder identity. All three reviewers agreed that the canonical `TipoActividad` taxonomy should be reused, the fixed-width row renderer is only a constraint-shape precedent, and the existing repeated XML parser should not be reauthored.

# `aeat-cli-userdocs-hardening` `W02.P03.S09` execution

Scope: Add a short "where to ask for help" route covering the issue tracker, diagnostic outputs to include, and what not to paste publicly.

## Description

Added a `Getting Help` route to `docs/index.md` and support guidance to `docs/how-to/index.md`.

The route tells users to use local command help, report bugs and documentation gaps on the issue tracker, include the command, command output, version output when available, and the smallest safe description of the profile, ledger row, modelo, period, or verification report involved.

It explicitly tells users not to paste tax ids, certificate material, bank account details, full justificantes, raw personal documents, unredacted log files, or personal documents.

## Outcome

Completed. The non-technical editorial reviewer reported no blockers for closing this step after the support route was added.

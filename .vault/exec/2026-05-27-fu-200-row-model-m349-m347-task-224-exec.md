# FU-#200 — extend ModeloDetailRow union: M349 operador + M347 contraparte (Task #224)

## Objective

Extend the `ModeloDetailRow` discriminated union with two new row types:

- `Modelo349OperadorRow` — EU intracomunitario operator row (M349, Pedro round-18 #2)
- `Modelo347ContraparteRow` — annual counterparty row with quarterly breakdown (M347, Ramón round-24)

Both extend the `--row TYPE FIELD=value` CLI mechanism established in S200.

## Changes Delivered

### `src/aeat/domain/modelos/_row_models.py`

- Added `_M349_NIF_PATTERNS` — per-country EU VAT NIF-IVA regex patterns (DE, FR, IT, PT, NL, BE, AT, IE, PL, SE, DK, FI, LU, GB) grounded in Council Directive 2006/112/EC Annex XI.
- Added `_M349_NIF_FALLBACK` — generic `^[A-Z]{2}[A-Z0-9]{2,15}$` fallback for countries without dedicated patterns.
- Added `Modelo349OperadorRow(BaseModel)` — fields: `row_type="operador"`, `codigo_pais` (ISO 3166-1 alpha-2, uppercased), `nif_comunitario` (non-blank), `razon_social=""`, `clave_operacion: Literal["E","S","T","R","A","I","M"]` (Orden HAC/174/2020 Annex II), `importe: Decimal` (non-negative). ConfigDict: `strict=True, frozen=True, extra="forbid"`.

- Added `Modelo347ContraparteRow(BaseModel)` — fields: `row_type="contraparte"`, `nif` (non-blank), `nombre=""`, `importe_Q1/Q2/Q3/Q4: Decimal = 0`, `clave_operacion: Literal["A","B","C","D","E","F","G","H","I"]` (Orden EHA/3012/2008), `pais_codigo: str | None = None` (uppercased when set). Property `importe_total`. ConfigDict: `strict=True, frozen=True, extra="forbid"`.

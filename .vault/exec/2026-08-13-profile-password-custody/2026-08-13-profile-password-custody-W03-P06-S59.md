# Have Sol Medium rule on the seventeen operator command subtrees the capsule cutover left unresolved

## Scope

- `src/cadrumo/entrypoints/cli/_config/ and src/cadrumo/entrypoints/cli/_bootstrap_exempt.py and src/cadrumo/entrypoints/cli/_config_payloads.py and src/cadrumo/entrypoints/cli/_config_sandbox_payloads.py and src/cadrumo/entrypoints/mcp/`

## Description

- Establish that the ruling this row assumed had been delivered was never
  persisted, and rule from the tree instead.
- Delete the orphaned declarations of verbs a completed retirement already
  removed, and follow the residue through every surface that assumed them.
- Carve out the compliance obligation with an explicit declared-unimplemented
  state rather than deleting its last visible trace.
- Absorb the allowlist step, since its entries name the same verbs.

## Outcome

The forcing evidence cleared: the module that failed twenty-five times now runs
one failed, thirty passed, with zero schema-resolution errors, verified
independently of the report. The single remaining failure is one of the stale
tests named below and is not attributable to this step.

**The headline finding is that the residue reached six surfaces, not one.** Each
is built on the same unstated premise -- that a declared schema implies a live
verb -- and each broke in turn as the previous was repaired: the schema
registry, the input-schema coverage gate, the result-to-input join which demands
an exact correspondence, the descriptor build which raised on a key with no
input schema, the operator action catalogue which targeted absent verbs, and the
risk table, whose own gate states that a removed verb must take its risk
declaration with it or the table asserts a door that is not there.

So **a verb's existence is declared in six independent places and none of them
is the authority.** The operator manifest declared none of the seventeen while
five other surfaces still described them, which is why the retirement could be
complete at the CLI and invisible everywhere else. That is rowed separately; it
outlives this step.

The ruling itself divided the seventeen correctly. Sixteen were residue of a
retirement already executed -- no manifest entry, no registered verb -- so
deleting their declarations is honesty about a completed decision rather than a
new one. The subject-access-request surface is carved out, its declaration
stating the unmet obligation in prose, held by two tests: one asserting the
declaration exists AND says something, since a blank reason would satisfy a
membership check while telling a future reader nothing, and an anti-tautology
arm proving the gate still refuses an undeclared missing verb and that the
exempted key stays out of the error. Without the second, the carve-out would be
indistinguishable from a hole in the gate.

Export and import were held rather than deleted, because their capability
question belongs to another open step. That instruction cost more than it looked
-- three of the six surfaces needed the held declarations honoured rather than
merely skipped -- and the resulting treatment includes a rule worth keeping on
its own merits: a verb declared absent must never reach the wire as an
advertised tool, because advertising a tool with no verb hands the operator
agent a dead instruction it cannot recover from.

The allowlist step was absorbed, since its entries name the same verbs and would
otherwise have left exemptions failing open. It now carries twenty-four entries
with none unresolving, measured with the command builder's own resolver rather
than a naive walk -- a first attempt using the naive walk reported all thirty
dead, because it did not materialise lazy subtrees.

## Notes

Scope was exceeded twice and both were reported rather than absorbed. The row
was extended to the MCP surface by ruling, since the failure was raised there;
executing it then required the operator action catalogue and the risk table,
neither in scope and both unavoidable, because this step's own deletions
orphaned them and leaving them would have shipped the break.

Three items were surfaced that belong elsewhere and are now rowed.

A deleted allowlist comment justified itself by citing a test that **does not
exist** -- confirmed by search. The comment also carried a real security
principle: a verb whose output leaves the encrypted store must stay login-gated,
because a target-scoped unlock does not establish recency. That principle was
recorded nowhere else and went with the entries, so it is rowed for the archive
export work to inherit.

Two stale tests were unreachable while the build crashed and are now visible:
one asserts a required argument on a command whose parameters are all optional
and which resolves to a different verb, the other is parametrised against a
command key with zero production declarations.

The row cost roughly twice what it should have, because the ruling it assumed
existed had been delivered as a report and never persisted. A full search of the
execution folder, every audit of the week, and the corpus by both keyword and
meaning established its absence. **A ruling delivered as a report is not merely
unrecorded, it is indistinguishable from no ruling** -- the same failure the
campaign-close discipline watches for, with the artefacts swapped.

# Measure the legitimate population before closing the discriminated-pair rows, and treat this row rather than the new refusal as their close condition. Load and construct through the wallet-balance projection, the binding-prefill resolver and the M303 carry-ingress path and confirm every legitimate row still constructs and still loads. Assert against the NEW provenance field, never against status. This row previously admitted a vacuous pass: with status still carrying provenance an implementer could satisfy the clause below by reading provenance off status, which is a control passing against the wrong field. So it now carries a second assertion only the ruled design can satisfy, that status is None on every non-AEAT path. The disconfirming observation stands: if any of those three paths carries a row whose provenance is not one of the five enum members, the enum is incomplete and S09 must be reopened rather than the row forced into an approximate member. Record the count of rows exercised per path, because a control exercising zero rows reads identically to one that passes

## Scope

- `src/cadrumo/application/calculations/tests/`

## Description

- Locate the three consuming paths by meaning, then confirm each entry point and
  every provenance-assigning producer with a targeted grep.
- Add one new population-control module measuring the legitimate rows the three
  paths carry, built over one shared population inside a single isolated
  encrypted runtime profile.
- Drive the four persisting producers through their real production surfaces:
  the operator seed primitive, the operator correction primitive, the local
  filing observation projection, and the AEAT filed-declaration persistence.
- Measure the wallet-balance projection over every stored row and run the
  offline balance query to prove the projection consumed them.
- Measure the previous-filing prefill resolver over four target periods, one
  per persisted provenance, running both the per-row registry projection and
  the end-to-end recurrence extraction.
- Measure the Modelo 303 carry-ingress path over both persisted ingress rows
  and the never-persisted states the Modelo 390 annual partition reconstructs
  from the same filed envelopes.
- Assert the provenance FIELD against the closed member set, assert register
  status is absent on every non-AEAT path, and gate on the property that each
  path carried at least one row.
- Prove every predicate bites with an out-of-repo probe, and correct the census
  reporter that crashed on an undeclared provenance before the instructive
  refusal could reach the reader.
- Run the formatter, linter, type checker, the focused control and the
  surrounding IVA-compensation family suite.

## Outcome

The discriminated pair admits its whole legitimate population. Twelve rows were
exercised across the three paths, four per path, and all five declared members
were carried by a live path.

The wallet-balance projection carried four rows, one each of aeat capture, app
filing, operator seed and operator correction, and the offline balance query
folded them into four lots totalling 280.00. The previous-filing prefill
resolver carried four rows, one per persisted provenance, resolving a
recurrence for every target: 120.00 from the operator seed, 90.00 from the
operator correction, 30.00 from the local filing and 40.00 from the AEAT
capture. The Modelo 303 carry-ingress path carried four rows, the two persisted
ingress rows plus two casilla reconstructions, and both reconstructions resolved
the pair of Modelo 390 annual partition bindings.

Per provenance across all paths: aeat capture three, app filing three, casilla
reconstruction two, operator correction two, operator seed two.

The disconfirming observation did NOT fire. No path carried a row whose
provenance falls outside the closed five, so the taxonomy is complete for the
measured population and the earlier discriminator step does not reopen.

The control is proven to bite. Six predicates were driven from outside the
repository with no tracked file mutated, and each raised: a zero-row census, a
census that lost a source row it was built to carry, a non-AEAT row carrying a
register status, a non-AEAT row carrying an expediente, a row whose provenance
is outside the closed five, and an AEAT capture with no expediente. The
legitimate baseline still passed, so the predicates discriminate rather than
refusing everything.

## Notes

The bite proof found a real defect in the first draft: the census reporter read
the enum value unconditionally, so the exact disconfirming case this row exists
to surface raised an attribute error before the instructive refusal could reach
the reader. The reporter now renders whatever provenance arrived and lets the
assertion name the finding.

Three failures in the surrounding IVA-compensation family are NOT owned by this
row and reproduce with this module excluded: the four-year-window refusal
asserts a period token against a translated message key, and two relation
prefill cases raise a no-active-bucket-session error because they open no
isolated profile. That module carries live peer work in progress and was read
but never edited.

The registry tree was intermittently unloadable throughout, from concurrent peer
authoring: a duplicate legal catalogue id, a fingerprint race under concurrent
registry writes, Modelo 100 dependency classifications failing their
previous-filing coverage rule, and one transient missing import in the core
identity namespace. Each is peer churn outside this row's surface; the focused
control passes cleanly whenever the tree settles.

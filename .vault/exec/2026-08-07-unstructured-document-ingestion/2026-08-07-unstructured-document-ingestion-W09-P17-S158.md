# Sweep the branch table asserting no branch consumes establishment where the law keys on identification, which is the inverse of the error that prompted the split and is cheap to gate while the table is being written rather than after. The intra-community goods family and the 349 population key on identification, so a branch demanding establishment there would ask for a fact the law does not turn on and refuse a resolvable operation

## Scope

- `src/cadrumo/domain/iva`

## Description

- Read the branch table and the party-fact split it rests on before writing the
  sweep the row specifies.
- Check the proposed assertion against the rows it would judge.

## Outcome

PREMISE REFUTED, and the row must NOT be built as written. This is recorded as
a result rather than a decline: the sweep it asks for would red on four
correct rows and the executor could have satisfied it by damaging them.

The row asks to assert that no branch consumes establishment where the law
keys on identification, naming the intra-community goods family and the 349
population as the cases at risk. Measured against the landed table, EVERY row
consumes the territorial establishment, and a shipped gate asserts exactly
that. The four intra-community rows consume BOTH facts.

That is deliberate and documented, with a legal reason the row did not have.
The intra-community families need the identification to say which Member State
reports the operation, and they need the place NARROWLY beside it -- not to
say which State a party belongs to, which is precisely the conflation the
party-fact split ended, but to place the supply in the peninsula and keep
Canarias, Ceuta and Melilla out of "otro Estado miembro". A row that reads a
residency is not thereby reading it as a registration.

So the inverse error the row was written against is real and was fixed by the
split; the assertion it proposes to lock that in would instead forbid the
correct shape. The property the row actually wants is already gated, twice
over: every rule declares a non-empty consumption drawn from the closed fact
set, and the rows consuming identification are pinned BY RULE ID rather than
derived from the same field under test -- so the expectation cannot assert
itself.

No change made.

## Notes

This is the dangerous row shape the plan preamble names: wrong in a way its
executor can fully satisfy. Nothing about the sweep announces difficulty. An
executor would have found four rows violating the new assertion and, reading
the row as authoritative, narrowed their declared consumption to make it pass
-- which would have stopped the producer demanding the establishment on
exactly the branches where a Spanish territory must be kept out of "another
Member State". The row was TRUE when authored, against a table that had not
yet split the two facts.

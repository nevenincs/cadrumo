# Record the four deferred review findings as follow-up rows without implementing them

## Scope

- `.vault/plan/2026-08-07-m303-carry-reconciliation-plan.md`

## Description

Four findings the review explicitly scoped out of this remediation needed rows so
they have an owner and a location rather than living only in a review message.

## Outcome

Four open rows were opened through the plan verb, each marked deferred and each
naming the file it concerns.

The first is a basis label that reports resultado for a refunded filing which did
declare the generated casilla. It is unreachable today because both fetched
callers pass a non-refunded disposition, but the governing decision record's next
step recovers the disposition from the justificante declaration type, which makes
it reachable, and it would then write an operator-facing locator describing
arithmetic the derivation never performed.

The second is a disposition-blind reconstruction of the available carry in the
annual partition, protected only transitively by an upstream rewrite in another
package and asserted nowhere.

The third is a directly filed available casilla that overwrites the available
figure without the generated component following, so the persisted state can hold
a pair violating the identity. Pre-existing and defensible, flagged only because
this fix's central claim is that the two fields are one decomposition.

The fourth is the governing record's unimplemented fourth bullet, feeding the
disposition into the IVA wallet gate. The review marked this plausible rather than
confirmed, and the row does not assert it as confirmed.

## Verification

The rows exist in the plan and are open. None of the four was implemented, which
was the instruction.

## Notes

Recording these as rows rather than as prose is the point: a deferral with no row
and no verification gate reads identically to delivered work at the next
review.

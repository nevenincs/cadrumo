# Repair the locale co-landing hook, which flat-globs the locales root while the catalogues are sharded per locale, so its key set is empty and both its invariants short-circuit

## Scope

- `dev/locales/_colanding.py`

## Changes

- `M` `dev/locales/_colanding.py`
- `M` `dev/locales/tests/test_colanding.py`
- `verify:` `pytest dev/locales/tests/test_colanding.py` -> `13 passed`
- `verify:` `_catalogue_key_sets(manager, repo, "HEAD")` -> `4 locales, 68112 keys each (was 0)`
- `verify:` `check_colanding(manager)` -> `0 findings`

## Notes

THE HOOK WAS BLIND, NOT MERELY WRONG. It read the catalogue with a glob for a flat file shape that
the shipped tree no longer carries, so it matched nothing, built no key sets, and every co-landing
check passed by finding no catalogue for a key to be absent from. Measured before the change, the
glob matched zero files where the tree holds hundreds. An empty result read as a clean pass.

THE DEFECT WAS DEEPER THAN THE GLOB AND FIXING ONLY THE GLOB WOULD HAVE BEEN WORSE THAN LEAVING
IT. The key sets were keyed by FILE. A catalogue now ships as a shard directory of many files and a
key lives in exactly one of them, so a per-file key set reports every key as absent from every
shard but its own. The invariant is per locale -- a key must land in all four -- so each locale's
shards are unioned into one set and the finding names the locale rather than a file.

Discovery now goes through the canonical pair that already exists for exactly this, rather than a
glob. That pair's own documentation names this failure and records that four call sites had already
died the same way when the catalogues were resharded; this hook was a fifth, and the pair warns
that a glob is the more dangerous mistake precisely because a hardcoded path at least raises while
a glob returns empty and reports clean.

THE ROOT CAUSE OF THE VACUITY SURVIVING WAS IN THE TESTS, and repairing the hook without repairing
them would have left it free to regress silently. Every existing test wrote FLAT catalogues, the
legacy shape, so the suite exercised a layout production does not carry and passed while the hook
was blind against the layout it does. A sharded fixture was added, with an anti-vacuity proof that
each locale yields a non-empty key set and teeth that a missing translation reds against the
sharded shape.

Two existing assertions were updated rather than the behaviour. They asserted a filename appears in
the finding text, and a shard directory has no single file to name; the finding now names the
locale, which is what an operator acts on. The behaviour they guard is unchanged and was verified
against the partial case, where the message correctly names only the one absent locale.

The now-live gate reports no findings against the current change, so bringing it to life did not
red on work already done.

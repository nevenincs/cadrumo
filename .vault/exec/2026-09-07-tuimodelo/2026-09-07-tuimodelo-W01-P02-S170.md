## Notes

The headroom was created by splitting the module three ways rather than by moving a number. The
closed classification vocabulary, the reviewed row table and the gate now each own one file, so
row growth and gate growth stop competing for a single ceiling. Nine later steps grow one half or
the other; before the split every one of them drew from the same 63 lines.

LEAVING THE OLD CEILING IN PLACE WAS NEVER AN OPTION, and an earlier reading of this step assumed
it was. The size ratchet fails on stale entries as well as oversized ones: an entry whose subject
measures at or below the default limit is reported as dead weight and reds the gate. The pin was
therefore only legal for a measured size between 1251 and its own value, so any extraction that
took the module below the default forced the entry's removal. The entry was deleted and the
generated entry count decremented; no number was hand-written, because deleting an entry asserts
no number at all and is exactly what the generator emits once the subject falls under the default.
The baseline was deliberately NOT regenerated: regeneration re-bands every other within-ceiling
subject and would absorb other lanes' in-flight growth to fix one key.

THIS DEVIATES FROM THE RECIPE'S OWN DOCUMENTED REMEDY, and the deviation is recorded rather than
taken silently. The recipe's prose says to pay debt down and re-run with the regenerate flag to
lower ceilings, which points at full regeneration rather than at removing one key by hand. The
key was removed by hand anyway, on two grounds a reviewer can check. First, it reproduces the
generator's output for that key exactly: the limit builder emits no entry at all for a subject
measuring at or under the default, so regeneration would delete this key and write nothing in its
place. Second, regeneration is not confined to this key; it re-bands every other within-ceiling
subject in the same pass, which would absorb three live offenders' neighbours mid-campaign while
other lanes are actively editing them. Nothing was absorbed and no growth flag was used. A
reviewer who prefers the documented path should run the regenerate flag without the
accept-growth flag and review all of its changed lines as a deliberate act; the one option that
is not available is leaving the stale pin, because the recipe exits non-zero on a ceiling that
outlived its subject and is wired blocking in continuous integration.

Two defects in this step's own work were found and corrected before verification. The gate briefly
re-exported the table symbol it merely consumes, which is the facade the architecture rule
forbids; the consumer now imports each symbol from its canonical defining module. And the scope
prefix the gate needs was a private name, so it was promoted to a public constant in the
vocabulary module rather than imported across a module boundary as a private.

TWO PRE-EXISTING FAILURES WERE MEASURED AND ATTRIBUTED RATHER THAN INHERITED SILENTLY. The
canonical-authority fixed point fails on a duplicate destination-authority definition in the
full-screen navigation module, which this change never touched and which is unmodified in the
working tree; that gate's own specification excludes the denominator by name. The object-name
audit is a standing burndown that was already red. Neither is this step's, and the size budget
reports exactly the three offenders it reported before.

One coordination remains open and is recorded rather than forced. A row in the registry
declaration hardening plan claims this module and its subject moved into the table half, but that
plan is dirty with another writer's live work, so its scope was left untouched.

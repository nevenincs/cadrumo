## Notes

The declaration now lives beside both entrypoint packages rather than inside one. The placement
is not invented: the out-of-process session protocol sitting next to it already established the
pattern and states the reason, which is that a contract both entrypoints must agree on gets
exactly one definition and neither package has to import the other to reach it. The frontend
already imports that sibling, so the path is proven rather than assumed.

The import contract permitted this without amendment, which was the point worth checking before
moving anything. It forbids the frontend from importing the command-line PACKAGE, not from
importing their shared parent, so a peer module is reachable from both sides.

The command-line package keeps a plain import of the symbol for its own field type and default,
and its export list entry was removed in the same change. That distinction is deliberate: a
module that imports a symbol to use it is a consumer, while one that re-exports it is a facade,
and the architecture rule forbids the second.

The live-tree reachability gate was run rather than its detector-teeth suite, and reports the
relocated module nowhere in its findings, so the move created no unreachable module.

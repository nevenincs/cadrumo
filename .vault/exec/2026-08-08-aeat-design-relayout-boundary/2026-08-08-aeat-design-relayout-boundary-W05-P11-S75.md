# Decide whether the ambiguous-revision refusal's localised sentence should name the filing year, deferred deliberately rather than overlooked - the year already reaches the operator through structured context and the raiser-supplied suggestion so the omission costs clarity rather than actionability, while changing the text means the four locale catalogues which currently carry several agents' uncommitted translations, so the trade was judged not worth it for information already delivered

## Scope

- `src/cadrumo/locales/`

## Description

- Weighed naming the filing year explicitly inside the ambiguous-revision
  refusal's localised sentence against the cost of touching four contended
  locale catalogues for a wording-only change.
- Recorded the deferral, and the reasoning behind it, in the campaign audit
  document rather than editing `src/cadrumo/locales/`.

## Outcome

Recorded in the campaign audit document under the finding
`ambiguous-revision-refusal-sentence-year-naming-deferred`. The decision is
deferred deliberately, not overlooked: the filing year already reaches the
operator through the refusal's structured context and its raiser-supplied
suggestion, so the sentence's omission costs clarity rather than
actionability. Changing it means touching all four locale catalogues
(`en`, `es`, `ca`, `hu`), which at the time of this campaign's closing phase
carry several other agents' uncommitted translation work in the same files.
The trade was judged not worth making for information the operator already
has by another channel. No locale file was edited by this Step.

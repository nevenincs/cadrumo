# Define command capability classes covering registry, profile custody, encrypted facts, network, browser, Google, calculation, filing, and state-free behavior

## Scope

- `src/cadrumo/entrypoints/cli/_command_schema.py`

## Description

Define a closed typed authority taxonomy for state-free, registry, profile
custody, encrypted facts, network, browser, Google, calculation, and filing
execution.

Attach orthogonal side-effect and calibrated performance axes through one
immutable, slot-backed command classification record.

Expand implied authority families transitively so declarations stay concise
without weakening later import gates.

Defer result-schema dependencies until projection is requested, keeping
classification metadata free of new Pydantic, application, and registry
imports.

Prove exact taxonomy closure, lightweight incremental import behavior,
authority implications, valid state-free computation, and every invalid
metadata branch with real tests.

## Outcome

The command-schema authority now provides a metadata-light classification
vocabulary suitable for joining to the live command census without storing a
second verb list. Every requested authority family is typed, state-free is an
explicit exclusive declaration, and side-effect and performance choices remain
independent.

Fourteen focused tests pass. Ruff formatting and lint and the canonical `ty`
checker pass. The mandatory review found two high-severity defects and one
medium test gap; all were corrected, and the final re-review approved the Step
with no remaining findings.

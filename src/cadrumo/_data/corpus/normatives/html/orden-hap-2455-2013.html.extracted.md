# Articulo 1. Aprobacion del modelo 165.

Se aprueba el modelo de declaración 165 «Declaración informativa de certificaciones individuales emitidas a los socios o partícipes de entidades de nueva o reciente creación».

# Articulo 4. Plazo de presentacion.

La presentación de esta declaración informativa se realizará en el mes de enero de cada año en relación con la suscripción de acciones o participaciones en el año inmediato anterior.

Modelo 231. Declaración Informativa. Declaración de información país por país (CBC/DAC4)

Gestiones

Presentación

La vía principal para la presentación del modelo 231 es mediante servicio web. Toda la información sobre cómo conectar con este servicio web la encontrará en la pestaña de Información y Ayuda.

Como una vía alternativa de presentación, y con el objetivo de facilitar la presentación a todos los contribuyentes obligados, se ha habilitado un formulario web para la introducción de los datos de la declaración.

También se ha habilitado la presentación del xml a través de un cliente de web service

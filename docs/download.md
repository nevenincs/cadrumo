# Get Cadrumo

Cadrumo is a command-line application. Install it, then run `aeat`. It works on
Windows, macOS, and Linux.

## What you need

- Python 3.13 or newer.
- Around 200 MB of free disk space.

No taxpayer data, AEAT credentials, or online account is involved in the
install. Cadrumo stores everything locally and encrypted; nothing about your
taxes leaves your machine.

## Install

Pick the channel for your platform from [Install channels](#install-channels)
below and run the command it lists. PyPI is the primary channel and installs the
`aeat` command with its bundled legal corpus into an isolated environment;
Homebrew and Scoop install the same package for platforms where a Python
toolchain cannot be assumed.

The channel table is generated from the shipped channel inventory, so the
commands there are the ones this release actually publishes.

## Confirm the install

```bash
aeat --version
```

A version number confirms the install. Then run the full workstation check and
add the optional extras you want (Google export, the live AEAT browser, OFX/QFX
import) by following [Install Cadrumo](workstation-setup.md), which covers the
dependency report, platform checks, and per-extra install commands.

To let an AI assistant such as Claude drive Cadrumo, continue with
[Connect an agent (MCP)](how-to/connect-an-agent.md).

## Two ways to work

`aeat` runs as ordinary commands that print their results:

```bash
aeat app overview status
```

Add `--tui` to work in a full-screen interface instead:

```bash
aeat --tui
```

Both drive the same engine and the same local records.

## Install channels

PyPI is the primary channel; Homebrew and Scoop install the same package for
users without a Python toolchain. Each release is install-tested on every
platform it claims before it is published.

Per-channel install paths:

**Python package**: Any platform with Python 3.13+

```bash
pip install cadrumo
uv tool install cadrumo
uvx --from cadrumo aeat
```

**Homebrew formula**: macOS (Apple silicon), Linux (x86-64 and arm64)

```bash
brew tap nevenincs/tap
brew install nevenincs/tap/cadrumo
```

**Scoop package**: Windows (x86-64)

```bash
scoop bucket add nevenincs https://github.com/nevenincs/homebrew-tap
scoop install nevenincs/cadrumo
```

## Usage

To navigate the full ADR set programmatically:

```bash
# List all ADRs
vaultspec-core vault list --type adr

# Search for a topic
vaultspec-rag search '<topic>' --type vault --doc-type adr --max-results 10

# View the vault dependency graph
vaultspec-core vault graph --feature <tag>
```

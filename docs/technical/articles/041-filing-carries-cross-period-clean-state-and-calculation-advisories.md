## Calculation projections and knowledge

It supports Modelo 303 casilla 43 and Modelo 390 casilla 63; unexpected targets remain unresolved. An empty register yields zero without requiring a statutory parameter bundle. Otherwise, annual art-109 amounts require the current definitive prorrata percentage, supplied directly or for M390 from a stamped current-year M303 observation. A missing percentage yields an unresolved result instead of silently binding zero. Missing prior baselines stay silent rather than being fabricated as zero. The advisory is non-blocking. ## Implementation assessment

The strongest controls are separation of prefill from filing-grade clean-state gating; exact source-coordinate and registry-revision checks; explicit group-member coverage; typed evidence provenance; and suppression rows that state why an obligation was treated as absent. The main scoped follow-ups are the unpinned Modelo 720 taxonomy lookup and validating the callers of the zero-carry whitelist and suppression inputs. The `bienes_inversion_regularizacion` module also notes unresolved legal design questions around Modelo 390 parameter applicability and whether the annual box should restate the periodic value; code correctly leaves such cases unresolved rather than guessing. No tests are included in the assigned files and no runtime claims are made.

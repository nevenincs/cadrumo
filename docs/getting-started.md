# Getting Started

`aeat` is distributed as a single Python package. The recommended setup
uses [uv](https://docs.astral.sh/uv/) to manage the virtual environment
and the lock file.

## Install

```bash
uv sync
```

This installs every runtime and development dependency declared in
`pyproject.toml`, including the Sphinx documentation pipeline.

## Run the CLI

The package ships a Typer-driven CLI registered as the `aeat` console
script:

```bash
uv run aeat --help
```

Subcommands are organised by domain — for example `aeat doctor` for the
environment health check, `aeat auth init` for OAuth client provisioning,
and `aeat drive fetch` for pulling artefacts from Google Drive.

## Local checks

Three commands cover the most common verification loop:

```bash
uv run pytest                       # unit suite
uv run ty check src tests           # static type check
uv run ruff check .                 # lint
```

The full justfile recipe surface is documented inline; run `just` with
no arguments to list the recipes available on your platform.
